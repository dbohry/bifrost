# Bifrost

A self-hosted application dashboard, in the spirit of [Heimdall](https://github.com/linuxserver/Heimdall): one start page that bridges you to all your apps and services.

## Status

UI mockup only. Open [`mockup/index.html`](mockup/index.html) in a browser (no build step, no dependencies).

## Mockup features

- Tiles grouped by category, with favourites section and category tabs
- Live-style status dot and metadata per app
- Instant search (`/` to focus); Enter on no match falls back to a web search
- Add / edit app dialog (name, URL, category, colour, status check toggle)
- Settings dialog (title, search provider, link behaviour, auth)
- Light / dark theme toggle
