Full-bleed version for Android and PWA. The glyph stays inside the central 80%, so circle, squircle and square crops all keep it.

Colour
Default tile is brand blue #3b5bdb (#7c93ff on dark). In the app it follows each user's theme accent, with the glyph in the theme's "on accent" colour. Spectrum is the exception and never recolours.
Small sizes
Below 24 px use the tile version with the lighter two-arch glyph, never a thinner stroke. Minimum size 16 px.
Clear space
Keep a quarter of the icon's width free on every side. Do not stretch, rotate or add shadows.
Glyph only
Use the bare arches for monochrome contexts and next to the wordmark in the top bar on narrow screens.
