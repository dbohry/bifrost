Touch first
All targets are at least 44 px. Hover-only actions (edit, favourite) move behind a long-press or an Edit mode on touch screens.
Same data, different shell
Dialogs become bottom sheets on phones. The top bar becomes a bottom tab bar. Search stays one tap away.
Orientation
Phone landscape uses the tablet grid with the tab bar hidden. Tablet landscape uses the desktop layout.
