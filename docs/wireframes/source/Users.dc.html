Locked out or forgot a password?

Bifrost has no password reset on the sign-in page. Instead, reset it from the computer that runs Bifrost. This needs access to that machine, so only the person who runs it can do it.

Run on the machine that hosts Bifrost
docker exec bifrost /bifrost reset-password <username>
  • It prints a temporary password. The user must choose a new one at their next sign-in.
  • If the admin is the one locked out, use the same command with the admin's username.
  • Sessions on other devices are signed out after a reset.
