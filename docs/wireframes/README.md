# Wireframes

The screens Bifrost was designed from, drawn before any code was written. Each image is one board of the design canvas. Some details changed while building, so treat the app as the truth and these as the intent.

The editable sources are in [`source/`](source). Each `.dc.html` file is one board and opens in a browser as it is; `canvas.json` holds the board titles and where they sit on the canvas. They were made in a Claude design canvas, and `source/support.js` is the small runtime they need.
